# The River: outside-in timings

Hourly timings of [theriver.markets](https://theriver.markets) pages and its MCP endpoint, measured from a GitHub-hosted runner in the US (`data/us.jsonl`: HTTP code, time to first byte, total seconds, Cloudflare edge). Raw numbers, unedited. Our own server-side timings miss the network, so these keep us honest about what a visitor actually waits.
